# Changelog

## 0.1.3

- Check-in messages now direct guests to the property's secure channel. Access
  codes stay out of event notes, drafts, and exports.
- Added setup guidance for handling private guest requirements.
- Added tests for check-in privacy and expanded the event-planning evaluations.
- Updated package metadata for desktop execution in Codex.

See the [verification record](docs/verification.md) for test results and supported
installation methods.

## 0.1.2 candidate (not tagged)

Added directory listing metadata, a self-contained calendar icon, a published
privacy-policy source, and local listing validation. OpenAI directory approval
is separate from this release; see docs/openai-review.md.

Fresh Luna evaluations exposed missing canonical meal inputs, invented meal
overrides/serving categories, and an omitted household sender. Tightened meal
input validation, grounded meal instructions and household reconciliation. Helper
inputs and outputs now have explicit paired-file guidance. The qualification
report preserves failures and exact tested skill hashes across iterations.

Hardened optional-meal grounding, guest-digest privacy screening, and SVG resource
validation after an independent code review. The offline suite passes 223 tests.
Native local-package installation passed in Codex and Claude Code.

## 0.1.1

Added a verified local archive/restore helper and a read-only evidence-record
audit. Documented restoring a working event while retaining frozen archives and
excluding unrelated private records. Fixed the README installation command.

All seven expanded Luna hosting phases now pass automatic checks and separate
artifact review, including one documented corrective follow-up. Preserved earlier
failures and grader corrections. Public GitHub native installation passes in Codex
and Claude Code; portable installation supports the documented major harnesses.
The offline suite now has 186 passing tests, including Windows recorder lock-race
coverage. See docs/verification.md for the precise scope and limitations.

Added three phased, 24-person hosting evaluation packages with raw sources,
independent graders, observed helper/action journals, fresh-session recovery,
export/restore verification and mutation tests. Hardened the smaller journey
grader and separated automatic checks from independent artifact review.

Clarified required record/helper contracts, repair of local validation errors,
source-grounded identities and the non-authorizing fingerprint result while
developing larger Luna evaluations. Discarded early behavioral conclusions after
finding a contradictory evaluation instruction about reading installed skills;
the report distinguishes those attempts from corrected-protocol runs.

Added explicit persistent opt-out handling, complete private message previews,
UTF-8 records and separation of superseded versus current vendor quotes. Fixed
parallel observation-journal writes and rejection of malformed synthetic sends.
The initial expanded Luna run exposed failures and incomplete closeout. Its report
remains available alongside the successful 0.1.1 development evaluation.
