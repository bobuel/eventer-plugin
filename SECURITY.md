# Security and privacy

Do not post private event data or credentials in issues. Report a vulnerability
through GitHub private vulnerability reporting when enabled; otherwise ask the
maintainer for a private reporting route without including the exploit or data.
Eventer uses the permissions and tools of your harness. Instructions and local
records are not a security boundary against an unrestricted model or local user.
Review external actions, restrict tool access, and protect event folders with the
host's filesystem permissions. Helpers do not connect to the network. No telemetry.
Public eval fixtures are synthetic. Uninstall leaves event data and external
schedules intact; review and cancel schedules separately.
