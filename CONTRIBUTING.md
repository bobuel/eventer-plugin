# Contributing

Use Python 3.12+ and `python -m pip install -r requirements-dev.txt` in a virtual
environment. Run `python scripts/validate.py`, `python -m pytest`, and
`python evals/run.py offline`. Add a synthetic regression case for a behavior fix.
Use concise skills with discriminating descriptions and task-specific references.
No private records, secrets, real provider calls, or hosted runtime dependencies.
Native harness evaluations are opt-in and must record actual versions and failures.
See evals/README.md. Keep all supported skill folders together when packaging.
